# Fin Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar a Fase 1 do Fin como um nucleo financeiro executavel, testavel e seguro.

**Architecture:** O backend atual e um modular monolith FastAPI com SQLAlchemy, Alembic, Pydantic e PostgreSQL. O dominio financeiro deve ser separado progressivamente em arquivos menores por responsabilidade, mas sem refatoracao cosmética que quebre a entrega incremental.

**Tech Stack:** FastAPI, SQLAlchemy, Alembic, Pydantic, PostgreSQL, pytest. Frontend futuro: Next.js, TypeScript, Tailwind e shadcn/ui.

## Global Constraints

- Nao implementar o projeto inteiro em um unico lote.
- Toda entidade financeira deve ser isolada por `user_id`.
- Nunca aceitar `user_id` arbitrario vindo do cliente.
- Usar Decimal/Numeric para dinheiro.
- Migrations Alembic versionadas.
- O Fin pode consultar dados em modo somente leitura.
- Qualquer escrita feita pelo Fin exige `ActionProposal`, confirmacao explicita, idempotencia e auditoria.
- Open Finance, WhatsApp, investimentos, importacoes e billing SaaS ficam fora da Fase 1.
