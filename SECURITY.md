# Security Policy

Nao publique vulnerabilidades, tokens, dados financeiros ou credenciais em issues publicas.

Antes da hospedagem, substitua este texto por um canal privado de seguranca sob o dominio oficial do Nexo e documente o prazo de resposta. Inclua versao afetada, impacto, passos minimos de reproducao e evidencias sem dados pessoais reais.

Segredos encontrados no repositorio devem ser revogados imediatamente; remove-los do historico nao invalida uma credencial ja exposta.
